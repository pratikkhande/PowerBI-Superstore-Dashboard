# Power BI Superstore Dashboard

An interactive 3-page Power BI dashboard analysing sales, profit and units sold
across products, countries, segments and time (Sep 2013 – Dec 2014), using the Superstore dataset.

## Pages
- **Index**: navigation page linking to all reports
- **Sales Report**: 118.73M total sales, 16.89M profit and 1.13M units
- **Profit Report**: profit by product, country, segment and month
- **Units Sold Report**: unit volumes by product, country, segment and month

## Key Insights
- Paseo is the top-selling product (about 33M in sales).
- The USA and Canada lead in sales (about 25M each), followed by France and Germany (24M), then Mexico (21M).
- Government is the largest segment, with about 44% of sales.
- Sales peak in Oct 2014 (12.4M).

## Features
- Country slicer to filter every visual on the page
- Page navigation buttons and tooltips
- Data modelling in Power BI
